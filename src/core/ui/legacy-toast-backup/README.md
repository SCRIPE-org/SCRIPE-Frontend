# Legacy Toast System Backup

> Preserved before migrating to the Sileo Toast System (https://sileo.aaryan.design/).
> Contains the historical Radix UI (`@radix-ui/react-toast`) implementation:
> - `enhanced-toast.tsx`: Radix toast primitives, variants, ToastContent, ToastClose, ToastAction
> - `enhanced-toaster.tsx`: Radix viewport mount component
> - `use-enhanced-toast.ts`: Queue reducer, toast singleton, and hook
